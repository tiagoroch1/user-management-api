# 🚀 User Management API

API REST desenvolvida com Flask para gerenciamento de usuários, permitindo operações de CRUD (Create, Read, Update, Delete), com integração a banco de dados e interface web simples.

---

## 📌 Funcionalidades

* ✅ Criar usuário
* ✅ Listar usuários
* ✅ Atualizar usuário
* ✅ Deletar usuário
* ✅ Interface web integrada

---

## 🛠️ Tecnologias utilizadas

* Python
* Flask
* SQLAlchemy
* HTML
* CSS
* JavaScript

---

## ▶️ Como rodar o projeto

### 1. Clonar o repositório

```bash
git clone https://github.com/tiagoroch1/user-management-api.git
```

### 2. Entrar na pasta

```bash
cd user-management-api
```

### 3. Criar ambiente virtual

```bash
python -m venv venv
```

### 4. Ativar o ambiente

**Windows:**

```bash
venv\Scripts\activate
```

**Linux/Mac:**

```bash
source venv/bin/activate
```

### 5. Instalar dependências

```bash
pip install -r requirements.txt
```

### 6. Rodar a aplicação

```bash
python app.py
```

---

## 🌐 Acesso

Abra no navegador:

```
http://127.0.0.1:5000
```

---

## 🔗 Endpoints da API

| Método | Rota           | Descrição         |
| ------ | -------------- | ----------------- |
| GET    | /usuarios      | Listar usuários   |
| POST   | /usuarios      | Criar usuário     |
| PUT    | /usuarios/<id> | Atualizar usuário |
| DELETE | /usuarios/<id> | Deletar usuário   |
